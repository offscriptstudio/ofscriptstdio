# Offscript Studio

A modern React + TypeScript web application built with Vite, TailwindCSS, Supabase, Framer Motion, and GSAP.

## 🚀 Features

- ⚡️ **Vite** - Lightning fast HMR and build performance.
- 🎨 **Tailwind CSS & Framer Motion** - Sleek design, utility classes, and dynamic animations.
- 🗄️ **Supabase Integration** - Backend-as-a-Service integration ready for database & auth.
- 🔷 **TypeScript** - Full type safety and robust developer experience.

## 🛠️ Getting Started

### Prerequisites

Make sure you have Node.js (v18+) and npm installed on your machine.

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. If you encounter Rollup native module / `npm` optional dependency issues on macOS:
   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

### Development Server

Start the local development server:
```bash
npm run dev
```

### Build & Preview

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```

## 🧰 Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: TailwindCSS, PostCSS, Autoprefixer
- **Animations**: Framer Motion, GSAP
- **Icons**: Lucide React
- **Backend/Database**: Supabase JS Client
